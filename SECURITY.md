# Security Policy

## Supported versions

Security fixes are developed for the latest version on the default branch. Older releases may not receive patches; upgrade to the latest release where possible.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Security** tab using **Report a vulnerability** (private vulnerability reporting / security advisory). If that option is unavailable, contact [opeblow on GitHub](https://github.com/opeblow) privately.

Do not open a public issue or include exploit details in a public pull request. Include the affected component and version, steps to reproduce, potential impact, and any proof of concept that can be shared safely. Avoid sending real credentials or personal data.

The maintainer will acknowledge reports as promptly as possible, investigate with the reporter, and coordinate disclosure after a fix or mitigation is available.
